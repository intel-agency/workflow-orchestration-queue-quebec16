# OS-APOW Repository Summary

**Repository:** `intel-agency/workflow-orchestration-queue-quebec16`
**Description:** OpenSource AI-Powered Orchestration Workflow - A headless agentic orchestration platform

## Project Overview

OS-APOW transforms GitHub Issues into autonomous execution orders. The system uses a four-pillar architecture:

1. **The Ear (Notifier)** - FastAPI webhook receiver
2. **The State (Queue)** - GitHub Issues as distributed state
3. **The Brain (Sentinel)** - Persistent async orchestrator
4. **The Hands (Worker)** - Opencode CLI in isolated containers

## Environment Variables

### Required
- `GITHUB_TOKEN` - GitHub API authentication
- `GITHUB_ORG` - Target organization
- `GITHUB_REPO` - Target repository
- `WEBHOOK_SECRET` - Webhook signature verification (Notifier only)

### Optional
- `SENTINEL_BOT_LOGIN` - Bot account for distributed locking

## Development Commands

```bash

# Run tests

# Run linter

# Run type checker
uv run mypy src/

# Start notifier
uv run os-apow-notifier

# Start sentinel
uv run os-apow-sentinel

docker build -t os-apow .

docker-compose up notifier
```

- Import paths use `os_apow.*` (not `src.*`)
- All GitHub Actions must be pinned to full SHA
- Healthcheck uses Python stdlib, not curl
- UV is the package manager (not pip or poetry)
- Shell bridge scripts are in `./scripts/`
